# 开源发布检查清单 / Open-source launch checklist

> 仓库在变更为 Public 之前，应逐项核查。本文件用于提醒，不表示所有项目已经独立验证。

- [x] 核心 Skill 统一为仓库根目录的一份源码；插件包从源码自动构建。
- [x] 中英文 README 和安装/使用示例。
- [x] 贡献说明、安全反馈、版本说明。
- [x] MIT LICENSE 文件（**仓库所有者应确认是否符合自己的开源意图**）。
- [x] 本地结构与打包测试、基础 GitHub CI 配置。
- [ ] 仓库所有者确认 MIT 许可、版权归属和第三方材料授权。
- [ ] 维护者检查全部 Git 历史中的敏感信息、账号凭据、私有文档和未授权内容。
- [ ] 用实际公开论文测试：短文、公式密集论文、多图表论文、含官方源码论文。
- [ ] 在目标 Codex 版本实际安装并验证 Skill 调用。
- [ ] 在目标 ChatGPT 网页/手机端实际测试插件导入与调用（如果账号支持）。
- [ ] 确认 README、版本号、发布 ZIP 与 Release 标签一致。
- [ ] 检查 GitHub Issue、Discussions、私密漏洞报告和分支保护是否需要启用。
- [ ] 最后由仓库所有者手动将仓库可见性从 Private 改为 Public。

发布前不要把未完成的跨端兼容性测试描述成已经通过。第三方论文和源码的原始授权仍然适用。
