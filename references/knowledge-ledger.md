# Optional Cross-Paper Knowledge Ledger

## Purpose

Reduce needless repetition across a paper collection without assuming that exposure equals mastery.

This ledger is optional. Use it only when:
- the user asks to maintain a continuing reading project; or
- a project/workspace already contains a relevant ledger and the user is continuing that project.

Do not search unrelated personal history or use a personal profile. The default reader remains a beginner.

## What to record

Record concepts, not inferred personal traits.

| Concept | First introduced in | Plain-language meaning | Reports where used | Status | Evidence |
|---|---|---|---|---|---|
| ... | ... | ... | ... | Covered / Practiced / Demonstrated / Needs review | ... |

Statuses:
- **Covered:** explained in a report.
- **Practiced:** an example or exercise was included.
- **Demonstrated:** the reader successfully explained, derived, or applied it.
- **Needs review:** an explicit response or assessment showed a gap.
- **Not assessed:** no evidence either way.

## Rules

- Never mark a concept demonstrated just because it appeared in a report.
- If the concept was covered but not assessed, briefly recap it before building on it.
- If demonstrated, use a concise reminder and link to the earlier report if available.
- If needs review, explain it again from the appropriate prerequisite level.
- If no ledger exists, do not claim to remember what the reader knows.
- Do not create or update a persistent ledger unless the user requests continuity or the task clearly belongs to an existing reading workspace.
