# Quick start examples / 使用示例

下面是可直接复制的调用语句。示例不能证明工具已经访问到论文全文；实际报告应标注访问范围。

## 单篇论文（适合零基础）

\`\`\`text
$value-adaptive-paper-reading
请完整阅读这篇论文（如果全文可访问），先判断它对零基础读者的学习价值，
为不同内容设置掌握目标，并生成有原文依据的中文精读报告。
讲核心方法时，先列出对象/角色/程序/动作/数据结构/状态/指标，
再解释每个组件的输入、操作、输出和调用时机。
\`\`\`

## 讲清楚复杂算法或多 Agent 系统

\`\`\`text
$value-adaptive-paper-reading
请把我当成零基础读者。不要一开始就堆公式或组件名称。
先建立术语表和角色表，严格区分模型/Agent、可复用策略程序、
某个策略版本、一次策略调用、调用输出的动作、一次实际执行、
一轮决策和完整运行（只在论文确实区分这些层次时使用）。
用一个贯穿始终的具体例子，按“操作前状态—谁执行—输入—具体操作—
输出—操作后状态—下一步可见信息”逐步演示。
如果论文有在线与回放/模拟模式，分别演示同一动作在两种模式下
是否调用模型、是否生成新结果、是否重新评估、是否读取旧结果。
公式必须在所有符号的具体指代说清楚后再引入。
所有教学虚构数字标记为“教学示例，非论文实验数据”。
不要把教学上的功能拆分说成论文中存在多个独立 Agent。
\`\`\`

## 多篇论文的学习顺序

\`\`\`text
$value-adaptive-paper-reading
我提供了三篇论文链接。先绘制技术关系和前置知识依赖，
逐篇评估学习价值，推荐阅读顺序。不要给所有论文平均分配篇幅。
\`\`\`

## 有源码的算法论文

\`\`\`text
$value-adaptive-paper-reading
请精读论文，并在发现可信的官方代码仓库后，分析核心模型、损失函数和训练循环。
建立公式与源代码文件/函数的映射，标注版本和可能的实现差异。
默认只静态阅读，不安装依赖、不运行第三方代码。
解释源码时说明函数输入、输出、调用者、状态变化，并对应论文步骤。
\`\`\`

## 读完后验证理解

\`\`\`text
$value-adaptive-paper-reading
根据这篇报告的 M2 学习目标，给我设计概念解释题、简单计算题和方法追踪题。
特别检查我能否区分容易混淆的对象和角色。
提供答案和评分准则，但不要在我作答前把我标记为已掌握。
\`\`\`

## 用户反馈“没看懂”时重新讲

\`\`\`text
$value-adaptive-paper-reading
我没看懂刚才的解释。请停止推进新内容，先指出刚才哪些术语、
角色、时间尺度或数据流被混在一起；重新建立术语表和对象关系，
再用一个具体例子从初始状态逐步演示。不要只做简短总结或重复原话。
\`\`\`
